RepairGal eShop Jeykll GitHub Pages Site
====================

Agency theme based on [Agency bootstrap theme ](https://startbootstrap.com/theme/agency)

# About

This repository is used to host my Jekyll site on GitHub Pages, this site acts as a launchpad and method of advertising my passionate craft of console repair. The following Open Source Jekyll theme by y7kim was used as it's base: (https://github.com/y7kim/agency-jekyll-theme)
